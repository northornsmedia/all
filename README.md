# Northon's Media — 3D Coverflow Showcase

An ultra-modern, full-screen 3D Coverflow showcase portal for Northon's Media and its ecosystem of publications, alliances, and innovation platforms.

## ✨ Features

- **Animated Handwriting Splash Screen**: Custom vector handwriting intro powered by `opentype.js` and `framer-motion`.
- **Full-Bleed 3D Coverflow Carousel**: Physics-based drag & inertia throw, responsive card scaling across all desktop viewports with 60+ FPS direct DOM rendering.
- **Live Website Screenshot Previews**: Dynamically renders real-time website thumbnails of all 8 destination portals.
- **One-Click Actions**: Instant **"Copy link"** clipboard utility and **"Visit"** direct portal navigation.
- **Tech Stack**: React 18, TypeScript, Tailwind CSS, shadcn/ui directory structure, Lucide Icons, Vite.

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
